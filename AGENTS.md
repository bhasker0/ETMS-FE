# ETMS-FE Frontend Development Guidelines

- **Framework**: Next.js 14 App Router, TypeScript, Tailwind CSS, Lucide Icons.
- **PWA & Offline First**: Use Service Worker and IndexedDB for uninterrupted floor usage in embroidery units.
- **Multi-Language (i18n)**: Support English, Gujarati (`ગુજરાતી`), and Hindi (`हिन्दी`) across all UI labels and toasts.
- **Printing**: Ensure high-fidelity thermal slips (58mm/80mm) and A4 GST invoice print layouts.
